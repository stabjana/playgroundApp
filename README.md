# playgroundApp

The PlaygroundApp frontend is a friendly, modern web interface that lets people easily discover playgrounds in Helsinki via a map or a simple list view.
Each playground page gives a clear, cozy overview of equipment, age recommendations, seating, weather protection, photos, and community ratings.
It’s built with React and TypeScript and uses a clean visual style inspired by the City of Helsinki’s public design system. The frontend talks to backend APIs to fetch up-to-date playground data, images, and reviews in real time. Everything is responsive and mobile-friendly, so it works smoothly on the go. Future features like 3D playground models or extra community tools can be added without changing the core experience.
